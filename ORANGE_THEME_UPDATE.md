## 💡 Additional Customization

If you want to adjust the orange shade, you can modify these values in `lib/main.dart`:

```dart
// Lighter orange
seedColor: Colors.orange.shade300

// Darker orange
seedColor: Colors.orange.shade900

// Deep orange (red-orange)
seedColor: Colors.deepOrange

// Amber (yellow-orange)
seedColor: Colors.amber
```
